## Hello, I'm Artur

I'm an **Information Systems undergraduate at the Federal University of Uberlândia (UFU)**. I like understanding what makes software work — from the logic behind a small program to how an application handles data and communicates with other systems.

**Java Back-End is the direction I'm pursuing.** Along the way, I also explore front-end development because I want to understand the full journey of an application, not just one part of it.

This profile is a snapshot of that journey: university work, experiments, things I'm learning, and projects I want to keep improving.

> **My current goal:** write code I can explain, organize and improve — not just code that runs.

## How I approach learning

- **Understand before adding complexity.** I want to know *why* something works.
- **Keep the foundation strong.** Algorithms, object orientation and databases are worth revisiting.
- **Build, reflect, improve.** My projects document progress, not perfection.
